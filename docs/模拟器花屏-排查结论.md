# 模拟器花屏：排查结论

**结论：模拟器的视频解码器坏了，不是应用的问题。真机不受影响。**

---

## 一、花屏长什么样（实测截图）

- **只有顶部一条**在更新，内容确实在变
- **下面是一大片陈旧残影**（不是黑边，是旧帧没被擦掉）
- 整体偏色（绿灰 / 青灰交替）

---

## 二、根因：模拟器拿不到视频输出表面

日志里的直接证据：

```
[c2.goldfish.h264.decoder#309]
    setOutputSurface -- failed to set consumer usage (6/BAD_INDEX)
    query failed after returning 21 values (BAD_INDEX)
    Query output surface allocator returned 0 params => BAD_INDEX (6)
```

**解码器无法把解码后的画面交给渲染表面**，于是表面上是残缺的、没擦干净的旧帧。

### 为什么说是模拟器的问题

| 判据 | 结果 |
|---|---|
| 模拟器上有哪些 H.264 解码器 | **只有 `c2.goldfish.h264.decoder`** —— goldfish 是模拟器的虚拟硬件平台，真机不用它 |
| `OMX.google.h264.decoder` 呢 | 存在，但**不支持 surface 输出** |
| 换 GPU 模式（auto → host）有用吗 | **没用**，报一样的 `BAD_INDEX` |
| 换个应用会好吗 | **不会** —— 同样的花屏在 `TvWebPlayerView`（网页源）上也出现过 |

**最后一条最关键**：网页源和直连源是**两条完全不同的代码路径**，
唯一共同点就是那个解码器。

### 真机用什么

真机上是 `c2.android.avc.decoder`（纯软解）或厂商硬解
（`OMX.qcom.video.decoder.avc` / `OMX.MTK...` / `OMX.hisi...`），
它们都支持正常的 surface 输出，**不存在这个问题**。

## 三、旁证：流本身是好的

```
ExoPlayer 状态   : READY / playing / buf=12 秒 / video=854x480 / err=none
HLS 分片         : video/MP2T，4 秒/片，每片 ~890KB（约 1779 kbps）
```

**解码前的每一环都正常**，问题只出在"解码到表面"这一步。

## 四、顺手做的两件事（保留）

虽然修不了模拟器，但排查过程中发现并修了两个真问题：

### 1. 视频渲染改用 TextureView

Media3 默认用 `SurfaceView`（独立图层，由 SurfaceFlinger 单独合成）。
国产电视的定制 ROM 和模拟器在「缩放 / 裁剪 / 位于 Compose 布局内」时
经常合成出错。`TextureView` 走普通 View 绘制流程，和 UI 一起合成。

用的是 Media3 的公开 API：
- `setVideoTextureView(...)`
- `setEnableComposeSurfaceSyncWorkaround(true)`（官方就是为这个场景提供的）

**踩的坑**：第一次调用写在 `this.player = player` **之前**，日志报
「player 还没就绪，TextureView 未绑定」，等于没生效。已改到赋值之后。

### 2. 「省流」档位对固定清晰度的源无效

```
用户选：省流 → 期望 640x360
日志  ：直播清晰度上限 640x360@700k（手动=1）
实际  ：video=854x480
```

原因：我们的频道表里是**固定清晰度的 URL**（`_480P/playlist.m3u8`），
track selector 的 `setMaxVideoSize` 对它无效。

> 这个还没改完 —— 正确做法是按用户档位**过滤频道表里的源**，
> 而不是靠 track selector 去限制。留待下一轮。

## 五、怎么在模拟器上验证视频功能

模拟器的解码器不可用，所以**模拟器无法验证画面**。可以验证的是：

1. 选源逻辑对不对 → `adb logcat -s BawanSrc:I`
2. 播放器状态是否健康 → `adb logcat -s BawanLiveStat:I`（看 state/pos/buf/err）
3. 面板能不能操作 → 截图看光标
4. 焦点 / 按键 / 布局 → 截图

**画面本身必须在真机上看。**
