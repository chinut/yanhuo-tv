# 央视直播在老电视上播不出来：排查记录

面向的场景：**给老人用的老电视**（Android 5.1 ~ 8，1GB 内存左右，
系统 WebView 是 2015 年左右的 Chromium）。

---

## 一、已确认的根因

我们现在的直播架构是：

```
打开央视频网页（WebView）
    → 从页面里截获 m3u8
        → 交给 ExoPlayer 硬解
```

**第一步就是死路**：老电视的 WebView 太旧，渲染不出央视频的现代前端，
所以永远走不到"截获地址"那一步。表现就是"加载不出来"。

这不是参数能调的 —— 是架构问题。

---

## 二、试过的方案：换公开直连源（**不行**）

思路：如果存在公开的央视直连 m3u8，就能完全跳过 WebView，
只让 ExoPlayer 播一个流 —— 对老电视是数量级的减负。

### 做法

拉了 3 个社区维护的公开 IPTV 源：
```
iptv-org/iptv           cn.m3u
fanmingming/live        ipv6.m3u
Kimentanm/aptv          iptv.m3u
```
筛出 65 个央视频道名，逐个探测连通性。

### 结果：14 个"能用"，但**全部是海外转发**

```
http://74.91.26.218:82/live/cctv1hd.m3u8      ← 美国机房 IP
http://74.91.26.218:82/live/cctv13hd.m3u8
http://69.30.245.50/live/cctv6.m3u8           ← 同上
https://xykt-fix.github.io/play/a02e/index.m3u8   ← GitHub Pages
```

`74.91.26.218`、`69.30.245.50` 都是**美国机房**，不是央视 CDN。

**为什么不能用**：
- 国内访问要绕出国，延迟和丢包都很高
- 这类转发源随时会挂，没人负责
- 对老电视来说，"码率+高延迟"比现在更糟

其余候选（`[2409:8087:8:21::18]:6610` 这类 IPv6）**全部返回 502**，
是已经失效的国内 CDN 节点。

### 结论

**公开 IPTV 源这条路走不通。** 不要把它们塞进 LiveCatalog，
否则大概率比现在还差。

---

## 三、还没试、但值得试的方向

### 方向 A：不用 WebView，直接用 HTTP 取地址

央视频的网页是 **React 服务端渲染（SSR）**。页面本身没有视频地址，
是前端 JS 再去后端取。但那个**后端接口**可能是普通 HTTP 请求 ——
如果能用 OkHttp 直接调（带上必要的头），就完全不需要 WebView。

**这个方向最有希望**，因为：
- 老电视跑不动 WebView，但跑 OkHttp 毫无压力
- 取到地址后交给 ExoPlayer，和现在的硬解路线一样

**已经探到的**：
```
https://tv.cctv.com/live/cctv13/             HTTP 200，28KB，**不含 m3u8**
https://tv.cctv.com/live/cctv13/index.shtml  HTTP 200，另一个页面
https://vdn.apps.cntv.cn/api/getHttpVideoInfo.do?pid=...   **已连不上**
https://api.cntv.cn/live/getLiveUrl?channel=CCTV13         HTTP 404
https://api.cntv.cn/NewVideo/getVideoListByColumn?...      HTTP 200（节目单，不是直播流）
```

**结论：接口形态变了，命令行模拟不出来 —— 需要看浏览器里 JS 实际发的请求。**

**下一步（需要人操作，5 分钟）**：
1. 电脑 Chrome 打开 `https://tv.cctv.com/live/cctv13/`
2. 按 F12 → Network 面板 → 勾选 Fetch/XHR，过滤框输入 `m3u8`
3. 刷新页面，等播放器起播
4. 把那条返回 m3u8 的请求 **完整 URL + 请求头** 复制出来

> 这和短剧 App 的抓包**完全不同**：那个 App 有证书固定所以抓不到，
> 但**央视频是普通网站**，浏览器 F12 直接就能看到，没有任何障碍。

### 方向 B：用已有的自定义 m3u 功能

设置里**已经有**「自定义 m3u / txt 直播源地址」。如果用户能弄到一份
国内的 IPTV 播放列表（很多宽带运营商送，或者淘宝几块钱），
填进去就能用 —— 而且那条路是 100% 直连，老电视完全跑得动。

**要做的**：把这个入口做得更显眼、更好用（现在藏得比较深）。

### 方向 C：搭一个自己控制的转发

在能跑 WebView 的地方（比如用户的手机）截获地址，转发给电视。
复杂、依赖额外设备，**不推荐**。

---

## 四、我的建议

1. **不要再往公开 IPTV 源上花时间**（已验证不行）
2. **做方向 A** —— 直接 HTTP 取央视地址，彻底去掉 WebView
3. 同时把**方向 B** 的入口做好，给用户一条自己能掌控的退路

方向 A 是唯一能真正解决"老电视播不出央视"的技术路线。
如果它也不行，那就只能靠方向 B（用户自备源）了。
